字段类型说明

L2 · HTS 整表字段与覆盖

字段说明
htsnoHS 编码（含层级，如 8507.60.00）

03B · ForecastArena 数据

Candidate B · 无真实实时层，demo dataset 已落实

真实实时层：确认不存在

销量数据天然是企业私有（POS / OMS / ERP），不存在免密钥 + CORS 的公开源。B 的实时层只能由「用户上传」承担——这与方案 B 原本的定位一致，也意味着它按准入标准第 2 条不达标。

结论

A 两层真实数据全部打通，可以开工。L1 实时（Federal Register，CORS 全开、免密钥）+ L2 快照（USITC HTS 整表，35,502 条已下载验证），加上内置的品类样例票证，三层齐备，且无需任何 API 密钥。

B 拿不到真实实时数据，但 demo dataset 已落实（Favorita 300 万行，免登录可取，结构天然适配多级预测）。它的形态被限定为「用户上传 + 内置 demo」，按准入标准仍排在 A 之后。

执行顺序建议：A 先做（数据已就绪）→ B 次之 → 库存蓝图最后（它连 demo 都只能用模拟数据，但原型现成、改造成本最低）。

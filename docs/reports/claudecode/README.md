# 2026 供应链行业报告（1–9月）· Supply Chain Industry Report 2026 (Jan–Sep)

一份可交互的中英双语行业报告：可切换中国 / 国际视角，以 Q1、Q2、Q3、上半年、1–9月为时间窗口汇总并可视化数据，每个数字都链接到公开来源。

An interactive, bilingual (Chinese / English) industry report. Switch between the China and global views, and between five time windows (Q1, Q2, Q3, H1, Jan–Sep). Every figure links to a public source.

## 字体 · Fonts

中文一律使用系统字体（苹方、宋体-简、微软雅黑、Noto CJK），不下载中文网页字体。英文字体（IBM Plex Sans/Mono、Source Serif 4，约 240 KB）在页面渲染之后才从 Google Fonts 异步加载；在 Google Fonts 无法访问的网络环境（如中国大陆）下，页面照常立即显示，英文改用系统字体。

Chinese text always uses system fonts (PingFang, Songti, Microsoft YaHei, Noto CJK); no Chinese web fonts are downloaded. The Latin fonts (IBM Plex Sans/Mono and Source Serif 4, about 240 KB) load asynchronously from Google Fonts after the page renders. Where Google Fonts is unreachable, such as mainland China, the page still renders immediately with system fonts.

## 数据规则 · Data rules

- 只使用已公开发布、可核查的数据；每个数字在 `research/sources-log.md` 中登记来源。
  Only published, checkable figures are used; each one is logged with its source in `research/sources-log.md`.
- 尚未发布的数据显示"待发布"，不做估算；由累计值相减得到的季度数值标注"推算"。
  Figures not yet released show "Pending" and are never estimated; quarterly values derived from cumulative totals are marked "derived".
- 采用发布日可得的最新修订版，修订情况写在页面"方法说明"中。
  The latest revised release available on the publication date is used; revisions are noted in the page's methodology section.

## 标题图 · Hero image

`assets/hero.svg` 是报告的横幅标题图（1200×320）。左侧为报告中英文名称、口径和六个关键词：霍尔木兹、关税重置、AI 硬件、集运运价、供应链韧性、链博会；右侧为亚欧航线示意图（非地理比例）：上海经马六甲驶往欧洲的苏伊士、好望角两条航线，以及霍尔木兹支线。航线上的"船点"间距约与 IMF PortWatch 2026年1–9月日均通行船舶数成反比（马六甲 224.2、好望角 90.8、苏伊士 40.7、曼德海峡 33.6、霍尔木兹 19.8 艘/日）；霍尔木兹支线的点静止，表示通行近乎停滞。动画只用 CSS，系统开启"减少动态效果"时自动停止。内联进页面时颜色跟随页面主题，手机端只显示航线部分；单独打开时使用内置的明暗两套配色。

`assets/hero.svg` is the report's banner (1200×320). The left side carries the Chinese and English report names, the scope and six keywords: Hormuz, tariff reset, AI hardware, freight rates, resilience and CISCE. The right side is a schematic (not to scale) of the Asia–Europe lanes: Shanghai via Malacca to Europe through Suez or around the Cape, plus the Hormuz branch. Dot spacing is roughly inverse to average daily transits in Jan–Sep 2026 from IMF PortWatch (Malacca 224.2, Cape 90.8, Suez 40.7, Bab el-Mandeb 33.6, Hormuz 19.8 ships a day); the Hormuz dots stand still because traffic has all but stopped. The animation is CSS only and stops when reduced motion is requested. Inlined in the page it follows the page theme and shows only the map on phones; opened on its own it uses built-in light and dark palettes.

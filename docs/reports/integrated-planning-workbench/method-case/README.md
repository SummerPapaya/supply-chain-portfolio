# APP 01 · Integrated Planning Workbench

一个可运行的公开零售样本案例，用于展示需求计划、PSI 情景与品类管理如何形成同一条决策链。

## 打开

在仓库根目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8768/docs/method-case/`。应用为静态页面，无后端、账号、密钥或运行时依赖。直接双击 `index.html` 时，浏览器通常会禁止读取 `data.json`。

## 数据与复现

唯一业务数据源是 [Mendeley Data: Retail Transactions and Stocks Data](https://data.mendeley.com/datasets/27x8mjm8k4/1)，DOI `10.17632/27x8mjm8k4.1`，发布许可 CC BY 4.0。构建脚本验证两份原始 CSV 的 SHA-256；发布方将其描述为供机器学习使用的零售样本，底层企业来源没有独立核验。

```sh
python3 scripts/build_planning_workbench.py
```

脚本将下载文件放在 `.cache/planning-workbench/`，仅向应用目录写入汇总后的 `data.json`。已有本地文件时可指定 `--sales` 和 `--inventory`。原始 CSV 不随作品集发布。当前数据包覆盖 2025-06-01 至 2026-04-24 的交易与截至 2026-04-24 有效的库存记录，选择正向销售行最多的六个品类。重新生成后应运行 `python3 scripts/check_planning_workbench.py`。

## 口径

- **预测擂台**：按品类和日汇总正向销售件数；退货排除出预测目标，但计入近 28 天的净销售额、成本和毛利。使用最近三个连续的 28 天时间窗口，逐日做一步预测，比较上周同日、四周同星期均值与岭回归。按最近窗口最低 WAPE 推荐模型，同时公开三个窗口的表现、偏差和 MAE。最终模型使用全部历史重新训练，递推生成未来 14 天预测。回测的一步预测与未来 14 天递推预测难度不同，不能把回测 WAPE 直接当作未来误差保证。
- **库存起点**：按门店和 SKU 查找观测截止日有效的库存区间，同一键出现多个有效区间则构建失败。负在手量从可用量中排除，缺失记录保持未知。页面展示历史交易与库存区间的匹配比例，以及近 28 天售出 SKU 与当前库存记录的匹配比例；这两种比例不同。
- **PSI 情景**：未来品类销量按门店近 28 天正向售出占比分配。第 15 天后重复预测期第二周的日节奏，仅用于 30/60 天压力测试。假设到货量、到货日、分配规则和目标覆盖天数由使用者输入。每家门店每天满足销量不超过可用库存，未满足量单列。到货分配仅在品类层面，不能证明 SKU 可调拨或可采购。
- **品类行动**：建议是基于模型误差、库存、门店覆盖、毛利与退货的透明规则草稿。SKU 清单使用近 28 天销量速度和有效在手量作为筛查线索，不把品类预测硬分配到 SKU。操作员勾选核查声明后可以导出 CSV；没有自动提交采购单或调拨单。

## 已发现的负结果

`Scholar Footwear Retro Legend` 的岭回归在最后 28 天留出期 WAPE 为 **629.5%**，最佳简单基线为 **46.9%**。留出期销量 160 件，前 28 天 778 件；历史中有少数异常高峰。这个证据说明该候选模型在该时期失效，但样本缺少促销、缺货和价格记录，不能据此确定需求骤降的原因。应用保留这一结果，允许查看其诊断性 PSI，却阻止从明显失效的模型导出行动单。当前透明门槛是 WAPE 高于 60%，或比最佳简单基线差超过 10 个百分点；门槛本身是产品设计假设，真实业务须根据成本与服务目标校准。

另外，品类总在手普遍较高，部分情景的理性动作是暂缓采购、检查门店与 SKU 分布。若额外到货没有降低模拟未满足件数，应用会明确指出它只增加库存占用。不能为了展示“优化收益”而强行假设必须补货。

## 决策边界

没有真实采购单、到货、供应商交期、仓库库存、缺货暴露、价格/促销因子或 SKU 替代规则。可见销量并非潜在真实需求。尤其是门店总量看似足够时，某些 SKU 仍可能缺货；跨店调拨必须核实同一 SKU 的可用量与实际运输约束。

FreshRetailNet-50K 的缺货偏差实验属于另一份数据集和方法案例；其数值不会进入本应用的 Mendeley PSI 情景。这里的机器学习组件是可复算的岭回归，行动文字由显式规则生成，没有调用或暗示实时大语言模型推理。

01 / NARRATION SCRIPT

90 秒现场讲解路径

00–20 秒 / 预测

先问模型是否可信

在“预测擂台”选择业务大类、产品线，再下钻 SKU。七种模型分开显示选模期与最后 28 天独立测试；指出测试误差变差、低样本回退或层级差额。

打开预测擂台 ↗
20–40 秒 / PSI

改变假设，看库存代价

比较 90%、95%、98% 情景的补货量、期末库存与模拟未满足；改交期或容量，检查逐 SKU × 门店滚动和数量守恒。说明服务目标只是安全量参数。

打开 PSI 决策台 ↗
40–60 秒 / 品类

把信号交给负责人

用 ABC–XYZ、净销售额、退货和风险门店筛选 SKU；打开一条商品证据，记录“纳入 / 暂缓 / 不采纳”及原因。导出的仍是待复核建议。

打开品类行动台 ↗
60–90 秒 / P1 负结果

计划与执行记录可能分叉

切到独立合成案例：促销日预测明显偏低，缺货日未测损失被排除；建议 72 件，合成下单 18、收到 12 且晚于 ETA。模拟缺口为 0，同日合成已测缺口为 3。

02 / NEGATIVE RESULT

失败案例要能说清楚

在固定合成规则与默认 95% 情景下，已标注促销日 WAPE 为 63.3%，其余有记录日为 8.3%；14 个有记录的 SKU × 门店 × 日中有 13 个可比较，另 1 个缺货日因损失未测而排除。不能由此推断促销造成预测误差，因为活动强度、价格及其他条件没有控制；订单也未按建议执行，因此模拟与观测缺口的差异不能单独归因于模型。

03 / REPRODUCIBILITY

如何复核这段演示

固定生成规则

合成销售覆盖快照前 168 天，后续观测 7 天；SKU、门店、销量节奏和异常事件由 synthetic-case.mjs 定义。日期相对当天平移以便重复演示，所有记录仍为虚构。

计划与执行分开

公开样本和合成案例各有数据版本。合成回执只绑定当前默认情景；改模型或参数后，原回执不再自动匹配新情景。

真实业务验收仍待完成

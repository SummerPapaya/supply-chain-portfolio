PSI ENGINE · INVENTORY RECONCILIATION

进销存守恒验算台

psi-conservation-engine

把「库存为什么对不上」从一句抱怨变成一台可以当场复算的仪器：以 6.1 万个账目、28.5 万个库存区间为底，对 21.5 万个相邻差分对逐对套用同一条恒等式 adj =（期末 − 期初）+ Σ销量，每一对都被判进「守恒 / 推断到货 / 未解释负差」三类中的恰好一类。不好看的部分照原样摆出来——这是本站唯一一个把负结果放在第一屏的工具。

  • 两种验法都摆在页面上，且不混为一谈：600 个账目样本里的 4,509 个差分对可以逐条在浏览器里重算（「自己验一遍」，与构建期共用一份实现 psi-core.js）；全部 60,968 个账目的判定条数另有一份按需加载的索引（gzip 97 KB，不点不下载），相加即得 215,180 与三分，与构建期逐位相等。样本证明算法对，全量证明公布的那几个数是真的——两者互不替代
  • 三分结果不挑好看的：守恒 78.62%（169,176 对）· 推断到货 16.15%（34,762 对）· 未解释负差 5.22%（11,242 对）；五分之一以上的差分对无法用单一恒等式解释，这是数据本身的性质，不粉饰、也不合并进「其他调整」
  • 两套退货口径并列、不做裁定：主口径把退货行排除在销量之外，备选口径把退货当作回库；两者判定不同的差分对 4,976 个（2.31%），页面同屏显示并标注冲突来源，不单方面裁决
  • 局限面板是「一等交付物」：默认展开、不提供收起，9 条局限每条配一个已量化的事实与一个具体下一步；本版本解决不了的直接写「本版本不解决」，不塞进脚注
  • 数据边界写在明面上：来源为 Mendeley 脱敏重采样数据集（CC BY 4.0），渠道与门店类型各仅 1 个取值、推断到货中 69% 为单件——不得描述为「某零售商的真实 ERP 数据」；换成企业真实进销存后，两套验证断言必须整组重写
已接入 · 免费 Mendeley DOI 10.17632/27x8mjm8k4.1（CC BY 4.0，可再分发，快照已内嵌）· 纯静态托管，浏览器直连，无服务端、无密钥、无接口配额
需接入 · 视数据源 换成企业真实进销存（ERP / WMS 导出）时，瓶颈不在算力而在数据治理：同一 SKU 的口径对齐、退货与调拨单据的语义区分、盘点差异的归因——A1–A16、F1–F12 与 V-A–V-E 三套断言要整组重写，否则换一份数据之后「守恒率」这个数字就不再有意义

## ⚡ 2. Architectural Pillars & Core Capabilities / 核心架构与系统机制

### 📅 A. Multi-Period Reporting Window Switcher / 动态时序报告期切换
Unlike static PDF reports, our dashboard is architected around a reactive time-series state engine. Users can toggle instantly between five comprehensive reporting periods:
- **2026 H1 (Current Headline Baseline)**: Full first-half forward projections & real-time telemetry calibration.
- **2026 Q1 & 2026 Q2**: Granular quarterly performance breakdowns and seasonal freight surge modeling.
- **2025 H2 & 2025 FY**: Historical benchmarking and year-over-year (YoY) inflation contrast analysis.
* **Instant Synchronicity**: Switching windows automatically updates WCI rate benchmarks, Supply Chain Stress Indices (SCSI), Recharts trendlines, and Gemini RAG grounding context.

### 🛰️ B. Real-Time Telemetry MUX Ticker / 4秒实时高频运价与压力指数流
Engineered for trading-desk responsiveness, the top telemetry ticker streams live industry pulse data every 4 seconds:
- **World Container Index (WCI) Spot Rates**: Transpacific, Asia–Europe, and transatlantic benchmark rate indicators.
- **Supply Chain Stress Index (SCSI)**: Global congestion and capacity utilization metric (0–100 scale).
- **Interactive MUX Controls**: Pause/Resume streaming, manual forced cloud-lightning sync, live server latency display (`<15ms`), and system clock synchronization.

### 🤖 C. Gemini 2.5 Search Grounded RAG Assistant / 智能体检索增强决策中心
Integrated directly into the workspace, the AI assistant delivers verified, real-time logistics intelligence:
- **Server-Side API Protection**: All generative queries pass through an isolated Express backend proxy (`/api/analyze`), ensuring zero client-side exposure of `GEMINI_API_KEY`.
- **Google Search Grounding**: Utilizes `@google/genai` with the `googleSearch` tool to verify live port congestion, freight rate updates, and geopolitical breaking news.
- **Preset Executive Prompt Library**: One-click prompt triggers for C-level briefings on Sino-Mexican border tariffs, Red Sea insurance premiums, and battery cold-chain routing.

## 🔒 6. Enterprise Security & Privacy Protection / 企业级安全与隐私

- **Zero Client-Side Secret Exposure**: All interactions with Google Gemini AI models are proxied strictly through our custom backend endpoint (`/api/analyze`). The `GEMINI_API_KEY` resides securely in environment variables and is never leaked to browser networks or client bundles.
- **Sandboxed Container Compliance**: Fully compatible with strict ingress reverse proxies routing external traffic exclusively through port `3000`.
- **Stateless & Offline-Resilient**: Core telemetry and statistical baseline datasets are cached locally, allowing the presentation layer to function smoothly even during transient API rate limits or offline network conditions.

## 🚀 7. Quick Start & Deployment Guide / 快速启动指南

### Prerequisites
- **Node.js** `v18.0.0` or higher
- **npm** `v9.0.0` or higher
- A valid **Google Gemini API Key** (from [Google AI Studio](https://aistudio.google.com/))

### Installation & Local Development

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/SummerPapaya/Supply-Chain-Industry-Research.git
   cd Supply-Chain-Industry-Research
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy the example environment file and insert your Gemini API key:
   ```bash
   cp .env.example .env
   # Edit .env and set GEMINI_API_KEY=your_api_key_here
   ```

4. **Launch the Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

### Production Build & Deployment

To compile the full-stack application for container deployment (e.g., Google Cloud Run, Docker):

```bash
# Verify TypeScript types and compile frontend static assets & backend server bundle
npm run build

# Start the compiled standalone production server
npm start
```
The production build generates a self-contained static web directory in `dist/` and a bundled CommonJS backend in `dist/server.cjs`.
